## 2. 本阶段交付范围

主题消费不再要求所有者/发布权限：普通data.read用户和有用户身份的Agent，基于调用产品当前挂载/权限，发现已发布关系主题，读取证据汇编和单独人工确认摘要，逐段展开精确原文及来源版本位置。没有已确认摘要时仍能读取当前事实，不自动生成或批准摘要。已撤销裁决、失效来源、未挂载或暂停消费不交付旧正文。

新增karda.topic_knowledge与RP只读API/页面，补的是实际消费功能；不是以新的评测/报告充当功能。真实Agent联调在代码完成后单独留证。
