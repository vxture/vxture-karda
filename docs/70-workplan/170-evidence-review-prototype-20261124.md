# K0 来源证据画布与审阅交互原型

状态：离线交互原型。使用公开开发资料；不构成 K2 知识服务、K3 正式工作台或业务事实发布。
设计依据：[160 持续知识架构](../30-design/160-continuous-knowledge-architecture.md) §5、
[K0 批次](80-knowledge-platform-rebuild-20261124.md)的交互路径验证要求。

## 1. 实际交付

`scripts/knowledge/export-review-graph.ts` 导出无需网络依赖的单文件 HTML。
数据经过既有项目族校验及开发区选择，保留项目在序列化前排除；导出的实际范围为
2 个开发项目、5 份文档、18 个章节、32 道 Agent 草案。图为 25 个节点、23 条包含关系。

大幅 SVG 主画布展示项目 → 文档 → 章节；点击任一层进入侧栏的子文档、章节或精确原文。
可按项目筛选、全文搜索、拖拽平移、缩放与适应画布。节点以形状内文字、类型和颜色共同表达层次。
原始招标公告、更正公告和附件分别保留版本及来源，不把历史原文改写成现行要求。

右侧题目选择器展示草案答案、预期支持章节及该题真实 BM25 Top5 命中情况；
未命中的预期证据同时用虚线及“Top5 未命中”文字标记。点击后仍可打开原始支持章节，
不为了界面观感隐藏漏召回。未知题说明候选不等于可回答。
选中章节展示来源版本、UTF-16 半开位置和对应正文，并可打开原公告/附件。

## 2. 使用和边界

```powershell
node portals/app/node_modules/tsx/dist/cli.mjs scripts/knowledge/export-review-graph.ts D:\new-review-graph\index.html
```

输出仅新建或逐字节一致复现；修改资料或界面后使用新路径。可以直接用浏览器打开 HTML；
本轮额外启动了仅绑定 127.0.0.1 的本地预览，实际文件为工作区外 `knowledge-review-graph-v2-20261124/index.html`。
没有 API、数据库写入、人工裁决提交或生产路由；页面不保存评审结果。
用户复核仍通过原 24 题包及新增 8 题包或对话逐题回复进行，本轮没有任何已接收的人审结论。

连线只表示资料归属/包含，不是业务关系本体、推理、矛盾裁决或已验证知识。
预期证据来自 Agent 标签；图不会证明标签正确。全部材料仍是有限时点快照，未监测后续更正。
本地结果也不覆盖在线授权、撤回、索引失效、多用户或大规模布局性能。

导出不携带原始 HTML；数据转义脚本闭合符、HTML 元字符及 JS 行分隔符，页面通过 textContent 显示原文。
CSP 只允许与内嵌代码匹配的 SHA256 脚本，没有外部字体、脚本、模型或数据请求。
这是保护本地审阅材料的实现约束，不能替代正式服务端授权。

## 3. 实际验证

- 原始资料导出为 5 文档/18 章节、32 题，未包含保留项目 ID、编号、原始 HTML；重复导出逐字节一致。
- 恶意脚本闭合文本保持为 JSON 数据；校验实际内嵌脚本 hash 与 CSP 一致。
- Playwright 实际浏览：1600×1000 桌面、390×844 窄屏均无横向溢出。
- JUNO 项目过滤后为 12 节点，不含另一项目标签；搜索无匹配时为 0 节点并显示空态。
- h1 的原/新公告证据可定位；更正节展示 UTF-16 [91,272) 与实际正文。
- x11 显示 1/2 支持证据命中，并同时在图和侧栏标记漏召回。
- 节点 Enter 激活后焦点及 aria-pressed 保留，正文显示“自本公告发布之日起5个工作日”。
- 浏览器控制台 0 错误/警告；全量本地测试 981 项，967 通过、14 项隔离数据库测试待 CI、零失败；TypeScript 和五项护栏通过。

截图与浏览快照保存在 git-ignore 的 `output/playwright/`，不把临时浏览工件纳入产品源码。
此批补足 K0 一条资料审阅交互路径，不关闭 K0b，不将 K3a/K3b 标为完成。
