# 图谱与本体三中心整体实施清单

日期：2026-11-27。owner已批准整体实施，按依赖顺序推进，无需逐板块重复审批。基础v0.12.51，索引详细计划见203。以下复用PostgreSQL/G6/Jena，不增加Neo4j或假设Ontos存在。

## I 语义图索引与查询中心

- [ ] I1 TDB2内部常驻运行时、持久卷、鉴权、健康、单写者与重启恢复。
- [ ] I2 当前授权完整有界图构建、持久账本、版本指纹、任务租约/重试/取消与CAS切头。
- [ ] I3 授权先于查询的邻域/有向多跳/类型过滤、稳定分页与真实缺口。
- [ ] I4 现有G6和Agent知识包共享Jena查询接线。
- [ ] I5 索引运营控制台、发布变化自动构建、失效立即阻断和清理。
- [ ] I6 DDL迁移、重建、集中验证、合并发布和回退。

## V 知识图谱探索与展示中心

- [ ] V1 保存视图：命名、复制、更新、删除、布局/坐标/筛选/焦点与当前授权恢复。
- [ ] V2 主题策展：实体/关系选择、分组、描述/标注，事实与人工注释分开，失效成员显式标记。
- [ ] V3 叙事步骤：顺序/标题/说明、焦点/高亮/证据选择、预览和返回探索。
- [ ] V4 演示模式：前后步/键盘/退出、相机和布局恢复。
- [ ] V5 已发布版本结构对比：增删改关系、来源版本、直接关联影响，无旧正文越权复活或因果虚构。
- [ ] V6 当前授权图片/JSON/演示导出、个人/同空间可见性与编辑历史。

## R 本体约束与规则治理中心

- [ ] R1 明确支持的类型层级、关系端点/形状约束与SchemaRef，版本化本地语义包。
- [ ] R2 规则草稿/不可变版本、启用/停用/回退、CAS及审计。
- [ ] R3 复用Jena确定性受限规则执行，限制规则语法/步数/结果规模，禁止自由代码/远程查询。
- [ ] R4 推导结论带规则版本、前提关系、来源证据与解释，区别asserted/inferred/suggested。
- [ ] R5 前提/来源/规则变化后重算，当前授权下推导，旧版本不绕过撤回。
- [ ] R6 管理页面与统一服务接入、集中验收与正常发布。完整OWL DL/外部Ontos真实联调不作本轮承诺。

## 交付规则

三板块构成整体目标；每个完整阶段必要CI可合并发布，但不可仅做底层样例就宣称完整。开发只必要定向/类型检查，阶段末集中回归；不做性能专项，不启本地服务器/浏览器或可见终端。用户70/output保持，I1暂停。最终逐项标记实现、验证、上线与独立外部/业务门槛。


当前：三板块首轮功能已编码，正在进入远程集中CI。尚未声明验收、合并或上线；生产保持v0.12.51。后续只文件读写及远程GitHub API，无本地命令进程。
