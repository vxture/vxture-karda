## 1. 六项交付

| 计划项 | 本批软件功能 |
| --- | --- |
| P1 服务管理 | 当前空间服务创建/列表/详情，名称说明、当前挂载可读库、能力和状态 |
| P2 消费策略 | 事实/主题/原文/知识包；原文回退、原文核验等级、数量和完整响应字节预算 |
| P3 版本与发布 | 草稿与当前发布隔离、对比/影响预览、原因确认、CAS/幂等发布、停用、回退新不可变版本及历史 |
| P4 统一调用 | 按服务ID的OBO工具及RP同执行器、实际版本/配置hash/证据/缺口/回退信息 |
| P5 调试与接入 | 中心及bench复用同调试组件、草稿/当前真实读取、结构化结果/证据、示例参数/无凭据JSON导出 |
| P6 追踪 | 无问答正文的持久开始/结束、实际版本/身份产品/耗时/安全错误/状态/步骤及精确用量key，筛选分页/详情 |

服务不是ACL，不把创建者权限转授给消费者。每次当前OBO身份、产品许可/调用产品挂载/所有配置库可见和真实来源/审核核验；源删除、撤权、停用及执行中配置切换不交付旧正文。facts/source沿用实际检索计量，空事实回退可能两次；外层工具不再收费。最终预算/版本拒绝前已完成的检索可能已计量，追踪保留用量关联。不生成模型答案；事实/主题/知识包不伪造原文等级过滤。超限响应完整拒绝，不破坏引用截断。

requestId唯一且重复不重放正文/重新计量；中断保留running诊断，不自动恢复副作用。版本冻结消费策略，不冻结历史知识；每次读取当前来源。发布/回退为新不可变版本；停用保留历史，不远程收回已交付内容。服务最多100/空间、20库/配置、20条分页、200库选择，输入64KiB、完整输出4096–262144 UTF-8字节。
