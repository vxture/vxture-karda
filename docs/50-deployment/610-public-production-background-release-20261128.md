## 操作与回退

员工获得显式产品编辑授权后，在公共知识库选择“新建任务自动后台执行”，建立条款候选任务；调度器按15秒周期取到期队列，最多5项/轮，不轮询浏览器。结果进入待审草稿，不自动审核/发布。临近会话过期或会话失效会暂停；重新登录后填操作原因，使用“重新授权并恢复”。权限撤销需授权管理员先恢复产品权限，否则不能恢复。

故障排查：operations_session_revoked（会话已撤销）、operations_session_renewal_required（需要员工交互刷新后重授权）、operations_permission_revoked（显式权限撤销）、operations_delegation_invalid（到期/篡改/密钥轮换）、operations_session_unavailable（中央核验故障有限退避）、operations_source_changed（原件版本变化需新建任务）。无权或无法核验时不加工。

紧急暂停使用Karda配置KARDA_OPS_WORKER_ENABLED=off；这不是平台变量。单项用前台暂停/取消。回退应用保留0050字段和已有记录，不删表；旧版本不具备后台调度，新自动任务应先停用/取消，避免回退后误以为仍在执行。运营入口保持关闭，除非专属workforce客户端配置和显式授权已完成。
