## 1. 完成功能

撤回保留挂载/订阅/已发布知识和历史，不删除消费者记录；现有知识消费及交付按当前visibility重新检查，其他用户旧领取不能在撤回后完成确认。已交付正文与外部副作用不能远程回收。旧状态以基线修订0呈现，不补造过去历史，无模型、外部消息、客户权限或数据变更。
