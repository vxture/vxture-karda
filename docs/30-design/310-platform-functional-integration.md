# 平台功能贯通与真实状态设计

状态：已批准批次209的实施设计；阶段验证中。依据208页面走查。

## 管理与消费

管理权限来自当前平台准入、本地角色、工作空间和库属主；消费还要求当前用户与调用产品的挂载及消费开关。挂载是工作集链接，不是授予资料访问权。

GraphStore仅允许Karda自身的实际库属主不依赖消费挂载管理图谱资产；共享库、其他调用产品仍需可见性和挂载。写入仍要求data.write和属主，发布/导出维持各自权限。生产管理要求Karda身份、当前角色和自有库，不再要求消费挂载。知识包读取保持原有挂载与消费暂停检查。

库工作区显示挂载状态和明确操作。新建RP库按与工具建库一致的规则挂载给创建用户的Karda工作集；历史库不做批量补挂载或权限修改。

## 导航与选择

库下共享布局提供资料、审核、原文检索、配置、图谱、规则、实体治理、贡献、连接器、来源、维护和设置入口。原文检索使用独立source-search页面，sources继续管理接入。已有图谱/发布/事实检索链接更正到检索页面。

全局搜索只返回当前工作空间内属主库/工作空间发布库的名称描述及这些库内未删除资料标题，最多20项；不返回原文，不调用模型，结果仍由目标页面重新授权。资料结果带documentId定位。

资料/实体/库选择器复用实际读取服务。库改变清除旧选择；高级ID只作为定位输入，服务端继续校验。文档操作菜单带入编译/重建上下文，失败任务提供同库资料、来源恢复和编译入口。

## 真实状态

评测已有持久运行器。没有已完成运行时返回实际集合与空指标，不能回退DEMO_EVALUATION。质量分数只来自已完成运行，未运行集合显示未运行。

队列保留历史未解决失败，时间窗口用于完成吞吐，不排除老失败；队列页面不展示登记的演示并发和新鲜度。无调用/无完成运行不展示0ms成绩。首页无检索就绪不能表达为整个平台不可用。资产/首页统一资料与条目口径，原始资料数量不等同发布知识。

图索引请求失败显示未知/错误，不显示0个实体的成功空态；重试和取消按索引状态启用。空发布链显示无发布内容。工具中文摘要与原始协议分层，OBO身份说明不再混同写入权限；本地实现与远端注册分开。

## 外部边界

当前无可读取的历史通知接口，面板提供实际待办和入口，明确不提供历史未读/已读回执。当前无可读取的授权视觉模型目录，OCR说明并保留高级模型代码，最终由服务端核验。两项接口缺口保持登记，不伪造列表。

完整本体可视建模属于下一批。Jena受限规则执行不自动认可事实。Atlas交换失败只提供可读诊断和显式恢复，不能靠放宽授权或静默重试解决。
