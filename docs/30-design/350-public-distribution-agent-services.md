# 公共分发与智能体服务设计

日期：2026-11-29。对应批准范围：213 的 B，D1–D6＋R1/R2。只修改 Karda。

## 归属与授权

公共资产归产品；客户消费使用 customer 身份。目录需通过现有 Karda C2 产品准入，公共可发现不等于匿名开放。首期明确为 included_with_karda，不臆造额外平台商业权益键。workforce 不能代租户启用。

工作区 owner/administrator 同时具备 product.manage 才可启停。绑定按 workspace＋public_library 存储，成员角色/用户白名单与 caller 产品白名单分别约束。读取仍核验当前成员、产品准入、data.read；搜索需要 ai.use，导出/原件需要 data.export。策略保存使用预期修订、事件指纹和事务防重。

## 发布与订阅

目录元数据与公共内容一起审核，review hash 同时覆盖两者；public_release.catalog 冻结领域、主题、地域、适用时间、性质、责任、边界、使用条件及模板。现有版本 catalog 为空，不自动迁为可分发内容。分发说明变更需独立审核后重新发布。

引用为只读，支持跟随当前或固定版本。固定旧版本仍要求库存在有效当前发布、两版本目录有效、来源当前存在且 hash/使用条件/URL 有效。来源撤回/归档、产品撤回、绑定停用、成员或调用方撤权均停止读取。版本回退复制原审核目录，不将草稿说明带入已发布目录。

## 消费链路

/api/public-knowledge 提供目录、绑定、只读检索、证据、图谱、导出和主动反馈。/api/public-knowledge/original 对保留原件重新核权、校验字节与 hash，返回附件；不返回底层对象键和长期签名 URL。首期多模态是保留原件消费，不宣称公共图表/公式自动视觉抽取已实现。

已发布公共快照通过 PostgreSQL 读取，G6 展示有界真实图谱；公共 Jena 索引仍沿用运营侧既有能力，本批不新增任意 SPARQL。证据包含 library/release/content hash/source revision/字符范围/来源 URL；无依据返回明确空结果。全响应有界，不截断已选证据。

ServiceConfig 增加可选 publicLibraryIds，旧配置无此字段时序列化和 hash 保持原样。私有 kbIds 继续走既有 workspace/挂载守卫；公共范围单独检查，不把公共库混入私有库 SQL。可发布纯公共或公共＋私有服务，复用既有服务版本、调试、OBO、任务上下文和完整包预算。未支持的公共游标/已认可摘要/规则或视觉筛选显式拒绝。

每次读取前后重新核验绑定、发布、来源和当前产品准入；服务最终返回前再比较公共版本指纹。所有响应 no-store。交付记录仅保存身份、版本、状态、结果数和错误码，不保存问题、答案或租户私有正文。搜索通过既有 karda.search 计量，公共请求和上下文分节使用稳定独立幂等键，归调用租户。

## 反馈与更新

用户主动填写反馈并明确确认不含私有正文；只提交必要公共问题、release 和可选 public artifact/request 标识。运营按 content.read 查看本库反馈，content.edit 处理为修订待办/已修订/不采纳并记审计。不能利用反馈入口读取客户私有正文；自动交付监测只聚合错误和无依据结果数。客户可查看自己的反馈，管理员看本工作区反馈与启停历史。

## 迁移与回退

0052 增加4表（121表），public_library.distribution 与 public_release.catalog；不迁移租户语料、不赋生产权限、不创建公共内容。基线、Prisma、增量及列权限同步。事件和发布版本不授予 UPDATE/DELETE。应用回退保留新增表，既有未分发服务保持可用；运营仍受外部正式授权接入条件约束。

## 验收边界

集中验证覆盖两工作区、成员/调用方、无权益、CAS/防重、版本/撤回、来源失效、公共上下文、组合私有挂载和不可变权限。数据库测试使用隔离夹具，不视为真实业务内容或外部 Agent 验收。平台757/758仍由平台交付；无员工真实接通和已审核公共内容时，生产目录允许为空。
